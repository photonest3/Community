# 代码审查检查清单 - 注释质量

> **项目**: PhotoNest 高容量图像库软件  
> **版本**: v1.0  
> **日期**: 2024-06-21  
> **适用**: C++ 代码审查、注释质量评估

---

## 📋 使用说明

### 审查流程
1. **代码作者**完成注释后，提交 Merge Request（MR）
2. **审查者**使用本清单逐项检查
3. **发现问题**在 MR 中添加评论
4. **作者修改**并根据反馈更新代码
5. **审查通过**后合并到主分支

### 评分标准
- ✅ **通过**: 90 分以上
- ⚠️ **需修改**: 70-89 分
- ❌ **不通过**: 70 分以下

## ✅ 检查清单

### 1. 文件头注释（15 分）

| 检查项 | 分值 | 评分标准 | 检查结果 |
|--------|------|----------|----------|
| 文件名正确 | 2 | 与实际文件名一致 | ✅/⚠️/❌ |
| 模块路径正确 | 2 | 与实际路径一致 | ✅/⚠️/❌ |
| 功能描述清晰 | 4 | 简要说明文件功能 | ✅/⚠️/❌ |
| 创建日期存在 | 2 | 格式 YYYY-MM-DD | ✅/⚠️/❌ |
| 修改记录完整 | 5 | 至少一条修改记录 | ✅/⚠️/❌ |

**常见问题**:
- ❌ 文件名与实际不符
- ❌ 功能描述过于简单（如"头文件"）
- ❌ 缺少修改记录
- ❌ 日期格式错误

**优秀示例**:
```cpp
///////////////////////////////////////////////////////////////////////////////
// 文件名: client_handler.h
// 模块: cefclient/browser
// 功能描述: CEF 浏览器客户端处理器，处理浏览器生命周期事件、
//           加载状态、键盘鼠标事件等
// 作者: PhotoNest Team
// 创建日期: 2024-01-15
// 修改记录:
//   2024-03-20  张三  添加 OSR 渲染支持
//   2024-05-10  李四  优化事件处理逻辑
///////////////////////////////////////////////////////////////////////////////
```

### 2. 类/结构体注释（20 分）

| 检查项 | 分值 | 评分标准 | 检查结果 |
|--------|------|----------|----------|
| @brief 存在且清晰 | 5 | 简要描述类功能 | ✅/⚠️/❌ |
| @details 存在且详细 | 8 | 说明设计思路、使用场景 | ✅/⚠️/❌ |
| @note 或 @warning（如有必要） | 4 | 说明注意事项或警告 | ✅/⚠️/❌ |
| 注释位置正确 | 3 | 在 class 关键字前 | ✅/⚠️/❌ |

**常见问题**:
- ❌ 只有 @brief，缺少 @details
- ❌ @details 内容过于简单（如"此类用于处理浏览器事件"）
- ❌ 注释位置错误（在 class 内部）
- ❌ 缺少线程安全、使用场景等重要信息

**优秀示例**:
```cpp
/// @brief CEF 浏览器客户端处理器
/// @details 继承自 CefClient，处理浏览器各种事件和请求。
///          该类是 CEF 浏览器与应用程序交互的核心桥梁，
///          负责处理浏览器生命周期、加载状态、键盘鼠标事件等。
///          采用单例模式设计，确保全局唯一实例。
/// @note 此类必须在浏览器进程的主线程中使用
/// @warning 不要在渲染进程中直接使用此类
class ClientHandler : public CefClient, ...
```

### 3. 公共方法注释（30 分）

| 检查项 | 分值 | 评分标准 | 检查结果 |
|--------|------|----------|----------|
| @brief 存在且清晰 | 5 | 简要描述方法功能 | ✅/⚠️/❌ |
| @details 存在（复杂方法） | 5 | 说明算法、流程 | ✅/⚠️/❌ |
| @param 所有参数都有描述 | 8 | 说明参数用途、约束 | ✅/⚠️/❌ |
| @return 或 @retval 存在 | 5 | 说明返回值含义 | ✅/⚠️/❌ |
| @note 或 @warning（如有必要） | 4 | 说明注意事项或警告 | ✅/⚠️/❌ |
| @see 存在（如有相关方法） | 3 | 参见相关方法 | ✅/⚠️/❌ |

**常见问题**:
- ❌ 参数有描述但返回值没有
- ❌ @param 方向错误（应为 [in] 写成 [out]）
- ❌ @return 描述不清晰（如"返回成功"）
- ❌ 复杂方法缺少 @details

**优秀示例**:
```cpp
/// @brief 加载指定 URL 到浏览器
/// @details 停止当前加载并导航到指定 URL。支持自定义协议，
///          如 photo://、local:// 等。URL 会进行编码处理。
/// @param[in] url 目标 URL 字符串，支持 HTTP/HTTPS/自定义协议
/// @param[in] bUsePost 是否使用 POST 请求（默认 false）
/// @param[in] extraHeaders 额外 HTTP 头（可选）
/// @return true: 加载成功启动; false: URL 无效或浏览器未就绪
/// @note 如果当前有页面正在加载，会先调用 StopLoading()
/// @warning URL 长度不能超过 2048 字符
/// @see OnLoadStart(), OnLoadEnd()
bool LoadURL(const CefString& url, 
             bool bUsePost = false,
             const CefRequest::HeaderMap& extraHeaders = {});
```

### 4. 私有方法注释（10 分）

| 检查项 | 分值 | 评分标准 | 检查结果 |
|--------|------|----------|----------|
| @brief 存在 | 4 | 简要描述方法功能 | ✅/⚠️/❌ |
| @details 存在（复杂方法） | 3 | 说明算法思路 | ✅/⚠️/❌ |
| @note 存在（如有必要） | 3 | 说明内部实现细节 | ✅/⚠️/❌ |

**说明**: 私有方法不强制要求完整注释，但关键的、复杂的私有方法应该有注释。

### 5. 成员变量注释（10 分）

| 检查项 | 分值 | 评分标准 | 检查结果 |
|--------|------|----------|----------|
| 所有 public/protected 成员有注释 | 5 | 说明用途和注意事项 | ✅/⚠️/❌ |
| 关键 private 成员有注释 | 3 | 说明用途（如有必要） | ✅/⚠️/❌ |
| 注释清晰易懂 | 2 | 无歧义 | ✅/⚠️/❌ |

**优秀示例**:
```cpp
/// 浏览器对象弱引用，用于发送消息到浏览器
/// @note 使用 WeakPtr 避免循环引用导致内存泄漏
CefRefPtr<CefBrowser> browser_;

/// 图像缓存字典，key 为图像路径，value 为缓存对象
/// @note 使用 LRU 策略管理缓存，最大容量 500MB
std::unordered_map<std::string, ImageCacheItem> image_cache_;
```

### 6. 代码逻辑注释（10 分）

| 检查项 | 分值 | 评分标准 | 检查结果 |
|--------|------|----------|----------|
| 复杂算法有注释 | 4 | 说明算法思路、公式 | ✅/⚠️/❌ |
| 关键业务逻辑有注释 | 3 | 说明业务流程、处理步骤 | ✅/⚠️/❌ |

### 7. 注释质量和规范性（5 分）

| 检查项 | 分值 | 评分标准 | 检查结果 |
|--------|------|----------|----------|
| 注释与代码一致 | 2 | 无过时注释 | ✅/⚠️/❌ |
| 使用中文注释 | 1 | 团队内部项目 | ✅/⚠️/❌ |
| 符合 Doxygen 规范 | 1 | 使用正确标签 | ✅/⚠️/❌ |
| 无废话注释 | 1 | 无无意义注释 | ✅/⚠️/❌ |

**禁忌示例**:
```cpp
// ❌ 废话注释
int age = 25; // 设置 age 为 25

// ❌ 注释与代码不一致
// 计算图像面积
int area = width * height * depth; // 实际上计算了体积

// ❌ 英文拼写错误
// This functon calcualte the image size
```
